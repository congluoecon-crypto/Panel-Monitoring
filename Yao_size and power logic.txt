================================================================================
       数据生成过程（DGP）数学规范文档
       聚焦：基础面板（base_t）与共同因子结构
================================================================================

本文档严格依据 `DGP discriptions (1).pdf` 中的文本描述，以纯数学语言
完整记录数据生成过程中"基础ARMA基底"与"共同因子施加"的所有公式、
维度、参数分布及操作规则。

实验固定设定：case = 2 （即序列个数 N = 2）

--------------------------------------------------------------------------------
1.  全局维度与时间参数
--------------------------------------------------------------------------------

令总生成时间长度为：
    T = MAX_T = 500 × 6 = 3000

生成时使用 burn-in 机制：
    实际生成 T + burnin = 3000 + 200 = 3200 个观测值，
    然后丢弃前 200 个，仅保留 t = 1, 2, ..., 3000 作为有效样本。

--------------------------------------------------------------------------------
2.  基础面板 base_t（纯 ARMA 基底）
--------------------------------------------------------------------------------

基础面板是一个 T × N 的矩阵，其中 N = 2（两列，对应两个序列）。
每一列独立生成，且每一列都是一个 ARMA(1,1) 过程。

2.1 序列1（第1列）的生成公式

设：
    φ₁ ~ U(0, 0.3)     （从 0 到 0.3 的连续均匀分布中随机抽取）
    θ₁ ~ U(0, 0.2)     （从 0 到 0.2 的连续均匀分布中随机抽取）

令 {ε_{1,t}} 为白噪声序列（均值为0，方差恒定，未指定具体方差值）。

则序列1在时间 t 的值 X_{1,t} 由以下 ARMA(1,1) 方程生成：

    X_{1,t} = φ₁ · X_{1,t-1} + ε_{1,t} + θ₁ · ε_{1,t-1}

约束条件：
    φ₁ ∈ (0, 0.3)
    θ₁ ∈ (0, 0.2)

2.2 序列2（第2列）的生成公式

设：
    φ₂ ~ U(0, 0.6)     （从 0 到 0.6 的连续均匀分布中随机抽取）
    θ₂ ~ U(0, 0.3)     （从 0 到 0.3 的连续均匀分布中随机抽取）

令 {ε_{2,t}} 为白噪声序列（与 ε_{1,t} 相互独立）。

则序列2在时间 t 的值 X_{2,t} 由以下 ARMA(1,1) 方程生成：

    X_{2,t} = φ₂ · X_{2,t-1} + ε_{2,t} + θ₂ · ε_{2,t-1}

约束条件：
    φ₂ ∈ (0, 0.6)
    θ₂ ∈ (0, 0.3)

2.3 基础面板的矩阵表示

将两列合并为 T × 2 矩阵：

    base_t = [ X_{1,t} , X_{2,t} ]

在后续公式中，该矩阵统一记作  B（形状 T × 2）。

--------------------------------------------------------------------------------
3.  共同因子结构（预先构建的因子与载荷）
--------------------------------------------------------------------------------

共同因子块在每次蒙特卡洛模拟（epoch）开始前一次性预先生成，且在整个
时间轴上保持恒定（非时变系数）。

3.1 共同因子矩阵 F（形状：T × 3）

F 的每一列是一个独立的时间序列过程：

    - 第1列（因子1）：
        F_{t,1} ~ iid N(0, 1)       （独立同分布的标准正态白噪声）

    - 第2列（因子2）：
        F_{t,2} = 0.5 · F_{t-1,2} + η_{2,t}
        其中 η_{2,t} 为白噪声，该过程等价于 AR 多项式 [1, -0.5]。

    - 第3列（因子3）：
        F_{t,3} = 0.8 · F_{t-1,3} + η_{3,t}
        其中 η_{3,t} 为白噪声，该过程等价于 AR 多项式 [1, -0.8]。

3.2 载荷矩阵 Λ（形状：3 × N，此处 N=2）

Λ 的所有元素独立同分布，均来自同一正态总体：

    λ_{i,j} ~ N(1, 1)    （均值为1，方差为1）

矩阵完整形式为：
         [ λ_{1,1}   λ_{1,2} ]
    Λ = [ λ_{2,1}   λ_{2,2} ]
         [ λ_{3,1}   λ_{3,2} ]

其中行索引 i = 1,2,3 对应三个因子，列索引 j = 1,2 对应两个序列。

--------------------------------------------------------------------------------
4.  施加共同因子结构（根据参数 r 进行截取与合成）
--------------------------------------------------------------------------------

设 r 为所使用的共同因子个数，取值范围为 r ∈ {0, 1, 2, 3}。
r 决定从完整的 F 和 Λ 中截取前几列/前几行来构建最终面板。

施加规则：
    给定 r，从 F 中截取前 r 列，从 Λ 中截取前 r 行，然后执行标准矩阵乘法，
    并将结果逐元素加到基础面板 B 上。

4.1 通用矩阵公式

定义：
    F_{[:, 1:r]} 为 T × r 的矩阵（取前 r 列）
    Λ_{[1:r, :]} 为 r × 2 的矩阵（取前 r 行）

最终生成的监测用面板 Y^{(r)} 为：

    Y^{(r)} = B + F_{[:, 1:r]} · Λ_{[1:r, :]}

其中 "·" 表示普通矩阵乘法，结果维度为 (T × r) × (r × 2) = T × 2。

4.2 分情形展开（按 r 取值）

● 情形 r = 0（不施加任何共同因子）：
    截取空矩阵，乘积为零矩阵。
    Y^{(0)} = B + 0 = B

● 情形 r = 1（施加第1个因子）：
    设 f₁ 为 F 的第1列（T × 1 列向量），λ₁ 为 Λ 的第1行（1 × 2 行向量）。
    Y^{(1)} = B + f₁ · λ₁
    逐元素展开：Y^{(1)}_{t, j} = B_{t, j} + f_{t,1} · λ_{1, j}

● 情形 r = 2（施加前2个因子）：
    设 f₁, f₂ 为 F 的前2列，λ₁, λ₂ 为 Λ 的前2行。
    Y^{(2)} = B + f₁·λ₁ + f₂·λ₂
    逐元素展开：Y^{(2)}_{t, j} = B_{t, j} + f_{t,1}·λ_{1, j} + f_{t,2}·λ_{2, j}

● 情形 r = 3（施加全部3个因子）：
    设 f₁, f₂, f₃ 为 F 的全部3列，λ₁, λ₂, λ₃ 为 Λ 的全部3行。
    Y^{(3)} = B + f₁·λ₁ + f₂·λ₂ + f₃·λ₃
    逐元素展开：Y^{(3)}_{t, j} = B_{t, j} + Σ_{i=1}^{3} f_{t,i} · λ_{i, j}

注意：对于任意固定的 r，所有被选中的外积项是同时求和并施加的，
不存在时间维度上的"逐步加入"。

--------------------------------------------------------------------------------
5.  备择假设（功效检验）中对共同因子结构的修改
--------------------------------------------------------------------------------

在功效检验（Power Test）的备择假设 DGP 中，基础面板 B 的生成方式不变，
但共同因子结构在特定断点 τ 处被修改。

5.1 A1 备择假设：载荷矩阵偏移（Loading Shift）

设 s = shock 为偏移强度标量。
断点前（t < τ）：
    Y_t = B_t + F_t · Λ

断点后（t ≥ τ）：
    Y_t = B_t + F_t · (Λ - s)

其中标量 s 被隐式扩展为与 Λ 同形状的全 s 矩阵，执行逐元素减法。

5.2 A3 备择假设：共同因子尺度偏移（Factor Scale Shift）

定义共同成分 C_t = F_t · Λ（T × 2 矩阵）。
断点前（t < τ）：
    Y_t = B_t + C_t

断点后（t ≥ τ）：
    Y_t = B_t + (1 + s) · C_t

其中 (1+s) 为标量，与 C_t 逐元素相乘。

5.3 A2 备择假设：因子突发（Factor Onset）

此假设下使用一个全新的独立因子 f_t（T × 1）和新的载荷 λ（1 × 2）。
断点前（t < τ）：
    Y_t = B_t

断点后（t ≥ τ）：
    Y_t = B_t + s · f_t · λ

其中 s 为标量强度，f_t 为 iid N(0,1) 因子，λ 元素来自 N(1,1)。

--------------------------------------------------------------------------------
6.  关键操作约束与备注（严格依据原文）
--------------------------------------------------------------------------------

- 所有随机抽取（φ, θ, λ, F 的随机项）在每次蒙特卡洛重复（itr）中重新进行。
- base_t 和因子结构在零假设（Size Test）下，整个时间轴 t=1 到 t=T
  上均保持参数恒定，不插入任何断点。
- 在功效检验中，断点位置 τ 由公式 τ = round(break_prop × m) + 9 确定，
  其中 break_prop = 1.1（聚焦运行设定）。
- 最终用于监测程序的数据是 Y^{(r)} 的**前 Tp × m 个观测值**（截取窗口）。
- 所有上述公式中的 N 恒等于 2（case=2），因此所有矩阵的列数均为 2。

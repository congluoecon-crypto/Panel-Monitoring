         内部统计量计算与报警逻辑 —— 完整技术文档

本文档基于 `pairwise_test_statistics (1).py` 源代码，详细描述了该监测程序
的内部工作原理，包括所有数学公式、算法步骤、参数设定和计量经济学细节。

--------------------------------------------------------------------------------
1.  监测目标
--------------------------------------------------------------------------------

给定两个时间序列 {Y_t} 和 {X_t}（t = 1, 2, ..., T），监测器旨在在线检测
从第 m 个观测值之后，两者之间的回归关系是否发生了结构性变化。

具体地，假设在“正常”状态下，去除各自自回归成分后的残差之间满足线性关系：

    e^Y_t = β * e^X_t + u_t

其中 β 在初始校准窗口内是常数。监测器递归地检查后续观测值是否仍与该
固定 β 兼容，一旦出现系统偏离，则发出警报。

-------------------------------------------------------------------------------
2.  符号约定
-------------------------------------------------------------------------------

- T        ： 原始数据总长度
- order    ： 用于消除序列自相关的AR阶数（通常为1）
- m        ： 校准窗口长度（训练样本量）
- tbegin   ： 固定偏移量，值为10，用于忽略初始不稳定期
- alpha    ： 名义显著性水平（通常0.05）
- n        ： 当前监测时点（从数据开头算起的总观测数），且 n > m
- β        ： 成对回归斜率系数（标量，当 lag=0 时）
- σ²       ： 回归残差的方差估计
- u_t      ： 回归残差

--------------------------------------------------------------------------------
3.  阶段一：AR滤波（去除序列自相关）
--------------------------------------------------------------------------------

函数：ar_forecast(data, order)

对每个原始序列分别拟合一个无截距的 AR(order) 模型：

    Y_t = φ_1 Y_{t-1} + φ_2 Y_{t-2} + ... + φ_p Y_{t-p} + ε_t

估计方法：最小二乘，使用正规方程形式 (X'X)^{-1} X'y，无截距项。

得到残差序列：

    e^Y_t = Y_t - Σ_{j=1}^{p} φ̂_j Y_{t-j}

同理得到 e^X_t。

输出的残差序列长度为 T - order，因为前 order 个观测值无法计算。

在后续步骤中，所有操作都在这些 AR 残差上进行，而不是原始数据。

--------------------------------------------------------------------------------
4.  阶段二：校准窗估计（Training / Calibration）
--------------------------------------------------------------------------------

函数：pairwise_ar_first_training_state

输入：前 (tbegin + m) 个原始观测值。

4.1 计算 AR 残差
对前 (tbegin + m) 个观测值调用 ar_forecast，得到残差序列。

由于 AR 残差比原始数据短 order 个点，需调整起始索引：
    tbegin_adj = max(0, tbegin - order)

校准窗口在 AR 残差中的位置为：
    tbegin_adj 至 tbegin_adj + m - 1

因此得到长度为 m 的校准样本 (y_t, x_t), t = 1,...,m。

4.2 估计回归系数 β（默认 OLS，lag=0）
模型（无截距）：
    y_t = β * x_t + u_t

普通最小二乘估计：
    β̂ = (Σ x_t y_t) / (Σ x_t²)

若 lag=1，模型变为：
    y_t = β_0 x_t + β_1 x_{t-1} + u_t
此时 β 为二维向量。

代码中还提供了 CO-AR 估计器（co_ar_estimator）作为备选，但注释指明
“网格脚本通常使用 OLS 路径”，故默认采用上述 OLS。

4.3 计算校准窗内的回归残差
    û_t = y_t - β̂ * x_t    (t = 1,...,m)

4.4 估计误差方差 σ²
使用分母为 m（而非 m-2 或 m-k）：
    σ̂² = (1/m) * Σ_{t=1}^{m} û_t²

这一选择与原始监测器实现严格保持一致，即使估计 β 消耗了自由度也
不作调整。

输出状态对象包含：β̂, σ̂², 校准残差, 分母 m, tbegin_adj。

-------------------------------------------------------------------------------
5.  阶段三：监测窗残差计算
-------------------------------------------------------------------------------

函数：pairwise_ar_first_statistic_at_n

对于给定的监测时点 n（n > m），执行以下操作：

5.1 对前 n 个原始观测值重新计算 AR 残差（递归更新）。
    注意：这一步会重新估计 AR 系数，而不是使用校准阶段的 AR 系数。
    这保证了残差始终基于最新可用数据的最优 AR 拟合。

5.2 使用校准阶段获得的固定 β̂，计算从第 1 到第 n 个所有 AR 残差
    对应的回归残差：
        ê_t = y_t - β̂ * x_t    (t = 1, 2, ..., n)
    （若 lag=1，则 ê_t = y_t - β̂_0 x_t - β̂_1 x_{t-1}，注意索引对齐）

5.3 截取监测窗口的残差，即排除前 m 个校准点：
        ê_{m+1}, ê_{m+2}, ..., ê_n
    监测窗口长度为 L = n - m。

-------------------------------------------------------------------------------
6.  阶段四：统计量汇总与边界比较
-------------------------------------------------------------------------------

函数：build_pairwise_statistic 和 boundary_function

6.1 标准化平方残差（item）：
    item_t = ê_t² / σ̂²        (t = m+1, ..., n)

6.2 偏差调整（item_adjusted）：
    由于 σ̂² 是从校准数据估计的，且回归中使用了 β̂，普通标准化残差的
    期望不等于 1。为使其期望为 1，代码引入调整项：
        item_adj_t = item_t - m / (m - 2)
    这里 m/(m-2) 是校准残差平方均值的期望调整因子（与 t 分布方差有关）。

    注：此调整在统计量累积之前进行，旨在使各期贡献的期望为零。

6.3 有符号汇总统计量 T_nn：
    T_nn = (1 / √(2m)) * Σ_{t=m+1}^{n} item_adj_t

    其中分母 √(2m) 是规范化因子，使得在原假设下 T_nn 的渐近方差为 1。

6.4 取绝对值得到最终检验统计量 T_n：
    T_n = | T_nn |

6.5 计算时变边界 g(n, m)：
    边界函数为：
        g(n, m) = (n-m)/m * √[ (n/(n-m)) * ( a_2(α) + ln(n/(n-m)) ) ]

    其中 a_2(α) 是取决于显著性水平的常数：
        α = 0.10  →  a₂ = 6.25
        α = 0.05  →  a₂ = 7.78
        （其他值默认回退到 7.78）

    该边界源自 Chu, Stinchcombe 和 White (1996) 的监测理论，用于控制
    渐近第一类错误率。

6.6 报警判定规则：
    如果 T_n > g(n, m)，则在时点 n 拒绝“无变化”原假设，宣布检测到断点。

-------------------------------------------------------------------------------
7.  主流程：实时监测算法
-------------------------------------------------------------------------------

函数：RealTimeMonitor_Dek_ar_single_pairwise_ar_first(data, order, m, alpha, estimator, lag)

步骤：
1.  固定 tbegin = 10。
2.  调用 pairwise_ar_first_training_state 获得校准状态（β̂, σ̂² 等）。
3.  初始化 n = m + 1。
4.  循环直到 n 达到最大可用时点（max_n = data.shape[0] - tbegin）：
    a.  调用 pairwise_ar_first_statistic_at_n 计算当前 n 的统计量 T_n 和边界 g。
    b.  若 T_n > g，则返回 n（首次报警时点）。
    c.  否则 n ← n + 1。
5.  若循环结束未报警，返回 None。

备注：监测是“在线”进行的，每次只使用截止到当前 n 的数据，且一旦报警即停止，
体现“实时监测”的性质。

-------------------------------------------------------------------------------
8.  关键计量经济学细节与设计选择
-------------------------------------------------------------------------------

8.1 无截距 AR 模型
    ar_forecast 使用无截距的 AR 回归，与原始 var 函数保持一致。这可能是
    基于残差已经去均值或为了避免过度参数化。

8.2 无截距的成对回归
    模型 y_t = β x_t 不含常数项。这意味着任何水平偏移（均值变化）不会
    被模型直接捕捉，而是反映在残差中。这解释了为什么 DGP 中的 A4（均值偏移）
    监测功率最低——水平变化容易被残差吸收，不显著影响斜率 β 和残差方差。

8.3 方差估计的分母为 m
    尽管估计了 β（消耗了自由度），但分母仍采用 m 而不是 m-2，这会使 σ̂²
    略有低估，但原实现如此，为保持一致性而保留。

8.4 偏差调整因子 m/(m-2)
    此调整使得 item_adj_t 在原假设下的期望接近于 0。它源于校准残差平方的
    期望为 σ² * (m-2)/m（在简单线性回归中），因此用 σ̂² 标准化后，其期望
    为 (m-2)/m，故调整为 1 - (m-2)/m = 2/m？实际上调整项为 m/(m-2)，这
    是 1 除以 (m-2)/m，即让期望变为 1 后减去该期望，使得调整后的项期望为 0。
    更精确地说，E[ ê_t² / σ̂² ] ≈ (m-2)/m，所以 item_adj_t = ê_t²/σ̂² - (m)/(m-2)
    其期望近似为 (m-2)/m - m/(m-2) ≠ 0，这可能是一个近似处理或原文特定
    的设计。代码中的注释明确说明这是“bias-adjusted normalized terms”，
    我们保留其原有形式。

8.5 边界常数的来源
    a₂ 值来自 Chu et al. (1996) 的边界公式，该公式基于 Wiener 过程的
    上确界分布，用于控制长期监测的累积 I 类错误。

8.6 可选估计器 CO-AR
    代码包含 CO-AR 估计器，它先对差分数据做 OLS，然后用 AR 模型拟合
    残差以调整动态，最后得到更稳健的 β 估计。但主流程默认使用普通 OLS。

-------------------------------------------------------------------------------
9.  与 DGP 实验的联系：功率表现解释
-------------------------------------------------------------------------------

根据 DGP 文档中的功率排序：
    A5（特质波动率偏移）最高
    A3（因子尺度偏移）次高
    A2（因子突发）中等
    A1（载荷偏移）较低
    A4（均值偏移）最低

原因可追溯至监测器的敏感结构：

- 该监测器本质上基于**残差平方和**的累积，因此对回归残差的**方差变化**
  非常敏感。
    → A5 直接缩放 base_t（即残差方差），故功率最高。
    → A3 放大共同因子成分，间接增大回归残差方差，功率次高。

- A2 新增一个因子，改变了回归残差的分布（引入新的方差源），也能被检测，
  但效果逊于直接的方差缩放。

- A1 改变因子载荷（即 β 的真实值），但监测器使用的是校准窗估计的 β̂，
  断点后残差会呈现系统偏差，但由于载荷变化可能部分被因子结构吸收，
  且监测器累积平方残差，对 β 的缓慢偏移不如对方差的突变敏感，故功率较低。

- A4 纯均值偏移，由于成对回归无截距，且残差平方对水平偏移不敏感（只要
  x_t 均值非零，均值偏移会转化为残差的线性趋势，但趋势在平方累积中
  的贡献不如方差突变更明显），因而功率最低。

--------------------------------------------------------------------------------
10. 总结
--------------------------------------------------------------------------------

本监测器是一个基于 AR 滤波、成对回归、累积标准化平方残差和时变边界
的在线变化点检测工具。其设计强调：
    - 去除序列自相关
    - 固定斜率假定
    - 利用残差方差的变化作为检测信号
    - 使用渐进边界控制误报率

所有上述细节均已在源代码中实现，本文档完整记录了其数学与计量经济学
实现细节，可作为进一步研究或复现实验的参照。
